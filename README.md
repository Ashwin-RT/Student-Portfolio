# Student Portfolio Manager

A beginner-friendly, browser-based portfolio manager for students. It lets each student create an account and manage their profile, education, skills, projects, and certifications without a backend.

## Features

- Local login and registration using browser LocalStorage
- Separate saved portfolio data for each user
- Profile editing and a public portfolio view
- Full CRUD operations for Education, Skills, Projects, and Certifications
- Custom delete confirmation modal
- Responsive navy, gold, and cream student portfolio interface
- Data remains available after refresh and after logging out and back in

## Run the project

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Register a new account and start adding portfolio details.

No server, database, internet connection, framework, or installation is required.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## Notes for demonstration

The project is self-contained in `index.html` so it can be opened directly for a college demonstration. LocalStorage is used only in the browser for this offline demo; it is not suitable for a production authentication system.
